Glossary

Configuration

The set of settings where administrators define which detectors are active, their severity levels, and enforcement actions.

Control

The rule that attaches a Configuration to a scope (LLM provider/models, users, groups) with an order.

Detectors

AI models that inspect prompts/responses for categories (PII, Code, Toxicity, etc.); all enabled detectors execute in parallel.

Threshold

The confidence cutoff a detector must meet to trigger its action (higher = stricter).

Severity

A logging/triage indicator shown in the dashboard/logs; it does not change enforcement behavior.

Default state

Fallback action for multi-label detectors when a specific label isn't set; per-label actions override it.

Anonymization

Optional replacement/masking of matched sensitive tokens (supported by certain detectors like Secrets) before forwarding to the LLM.

Action

What to do when a detector triggers - Detect (log, allow-through), Allow (explicitly allow; for binary, below-threshold inverts to block), or Block (deny).
