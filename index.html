Lab Description and Scenario

Welcome to the Zscaler’s AI Security Workshop Hands-on Lab. Throughout this lab, you practice skills that build on your understanding of Zscaler’s AI security capabilities. By the end of the hands-on lab, you are able to:

  • Navigate the AI Security dashboard across Public AI, endpoint visibility, and AI asset views.

  • Use Public AI overview, App Inventory, and usage insights to understand AI adoption patterns.

  • Test how public AI tools respond to direct and role-play prompts, and evaluate the risk of sharing sensitive data with them.

  • Use an AI assistant to analyze a suspicious log entry and assess attack risk.

  • Configure Zscaler AI Guardrails (ZGuard) detectors and interpret Detection dashboard views, transaction details, and detector outcomes for users and applications.

  • Explain how prompt and response detector outcomes reflect AI Guardrails policy intent, including PII masking.

  • Review Red Teaming probe settings, risk priority, and coverage.

  • Review failed Red Teaming test cases and apply remediation guidance to harden AI applications.

  • Some services may optionally prompt you to log in. If login is required, use a different service from the list.

Glossary

Configuration

The set of settings where administrators define which detectors are active, their severity levels, and enforcement actions.

Control

The rule that attaches a Configuration to a scope (LLM provider/models, users, groups) with an order.

Detectors

AI models that inspect prompts/responses for categories (PII, Code, Toxicity, etc.); all enabled detectors execute in parallel.

Threshold

The confidence cutoff a detector must meet to trigger its action (higher = stricter).

Severity

A logging/triage indicator shown in the dashboard/logs; it does not change enforcement behavior.

Default state

Fallback action for multi-label detectors when a specific label isn't set; per-label actions override it.

Anonymization

Optional replacement/masking of matched sensitive tokens (supported by certain detectors like Secrets) before forwarding to the LLM.

Action

What to do when a detector triggers - Detect (log, allow-through), Allow (explicitly allow; for binary, below-threshold inverts to block), or Block (deny).
